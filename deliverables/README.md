# Раскладка сэндвич-панелей

Редакция Р2: стеновые панели толщиной 150 мм.

Предварительные схемы для согласования и запроса стоимости. Габарит здания: 12 500 × 4 700 × 3 000 мм. Плоское покрытие без уклона; без вырезов под проёмы.

- [Вариант 1000 мм — PDF](panels_1000.pdf): 36 стеновых + 13 панелей покрытия, 163,70 м² без запаса.
- [Вариант 1200 мм — PDF](panels_1200.pdf): 30 стеновых + 11 панелей покрытия, 164,64 м² без запаса.
- [Оба варианта — ZIP с PDF, PNG и таблицами CSV](panel_layouts_1000_1200.zip).

Для скачивания откройте файл и выберите Download raw file. ZIP также можно скачать через Raw / View raw.

Высота стен предварительно 2850 мм; толщина стен 150 мм, покрытия 150 мм. Перед заказом подтвердить каркас, узел гидроизоляции, монтажные зазоры, рабочую ширину и пригодность выбранной модели покрытия к горизонтальному монтажу. Вариант 1200 мм не включает условную оптимизацию двух полос 500 мм из одной заготовки.

При толщине стен 150 мм торцы между длинными стенами имеют длину 4400 мм. Крайние подрезки торцов: 400 мм для рабочей ширины 1000 мм; 800 мм для рабочей ширины 1200 мм. Количество закупаемых панелей и общая закупочная площадь не изменились.
